# K8s Supply Chain Security

In this section, you will learn how to secure the entire container lifecycle - from code creation to deployment by implementing image signing, vulnerability scanning, and secure, automated CI/CD pipelines. Key concepts are as follows:

- Secure Registry
- Vulnerability scanning using `Trivy`

- Attestations & Signing using `cosign`
- Static Analysis using `checkov`
- SBOM (Software Bill of Materials)
