# Cyber Security - Key Concepts

## 01. `Vulnerabilities`

- A cybersecurity `vulnerability` is a weakness in software, hardware, network, or human processes that attackers can exploit to gain unauthorized access, steal data, or disrupt systems.

### Common Types of Vulnerabilities

- **Unpatched Software**
  - e.g. Outdated applications and operating systems
- **Broken Access Control**
  - e.g. Insufficient authentication
- **Injection Flaws**
  - e.g. SQL injection
- **Misconfigurations**
  - e.g. Poorly secured network devices or cloud storage settings
- **Human Error**
  - e.g. Phishing susceptibility or improper handling of sensitive data

### Vulnerability Management Process

- You can manage vulnerabilities to minimize risks through a structured approach often outlined by NIST:
  1. Identification

  2. Analysis
  3. Mitigation
  4. Testing

## 02. `Exploit`

- An exploit is a piece of code, software, or technique that leverages vulnerabilities (flaws) in hardware or software to execute unauthorized actions, such as stealing data, launching malware, or creating system outages.

### Vulnerability vs Exploit

- A vulnerability is an inherent flaw in a system (e.g., a bug), while an exploit is the method or tool used to take advantage of that flaw.

### Key aspects of Exploits

- **Purpose**
  - Attackers use `exploits` to gain unauthorized access, escalate privileges, or disrupt service.

- **Target**
  - Exploits can target software bugs, hardware weaknesses, or human factors (via social engineering).

## 03. `Payload`

- A `payload` is the part of a cyberattack that performs the intended malicious action, such as:
  - Stealing data
  - Encrypting files
  - Disrupting system operations

### Key aspects of `Payload`

- **Purpose**
  - To execute malicious activity once a system has been compromised.

- **Motive**
  - Steal sensitive data
  - Destroy files
  - Create backdoors
  - Spy on user activity

- **Examples**
  - Ransomware
  - Trojans
  - Spyware
  - Keyloggers
  - Botnet agents
