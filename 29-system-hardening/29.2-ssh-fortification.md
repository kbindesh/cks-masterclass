# SSH Fortification

In this section, you will learn how to optimize the security of K8s nodes (linux) by securing the SSH service.

- SSH (secure shell) service by default operates at port no. 22.

## Useful Linux commands

```
# To initiate SSH connection to a remote Server
ssh $HOST_DNS_NAME or $HOST_IP
or
ssh $USERNAME@$HOST_DNS_NAME or $HOST_IP
ssh bindesh@myappserver

# To connect to a remote server over SSH using SSH keypair
ssh -i $KEY_PAIR.pem $USERNAME@$HOSTNAME_or_$HOST_IP
ssh -i node.pem ubuntu@node1
```

# Useful Files

```
# Default location of authorized SSH key pair of any User
/home/$USERNAME/.ssh/authorized_keys
OR
~/.ssh/authorized_keys
```

## Hardening SSH Service

### To disable the SSH service for the `root` User

```
vi /etc/ssh/sshd_config

[Set "permitRootLogin no"]

# To disable password based authentication | only keypair based AuthN will be allowed
[Set "PasswordAuthentication no"]

# Reload the sshd Service
systemctl reload sshd
```
