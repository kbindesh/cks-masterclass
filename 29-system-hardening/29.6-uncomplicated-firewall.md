# Uncomplicated Firewall (UFW) Primer

## Install UFW

```
# Update all the packages listed in the default repository
apt-get update

# Check if the ufw is already installed
apt list | grep ufw

# Install ufw
apt-get install ufw

# Enable the ufw service
systemctl enable ufw

# Start the ufw service
systemctl start ufw
```

# Configuring UFW

```
# Check the status of the firewall (ufw)
ufw status

# Set outgoing rules | allow all outbound connections
ufw default allow outgoing

# To deny all the incoming connections
ufw default deny incoming

# Add an ufw allow rule | To allow ssh connection from an IP Address on TCP port 22
ufw allow from xx.xx.xx.xx to any port 22 proto tcp

ufw allow from xx.xx.xx.xx to any port 80 proto tcp

ufw allow from xx.xx.xx.xx/24 to any port 80 proto tcp

# To deny access on a specific port from anywhere
ufw deny 80
```

- Enable/Activate the Firewall

```
# Kindly check all the rules before activating it
ufw status

# If you're happy with the preceding command result, enable the firewall
ufw enable
```

- Delete a Firewall rule

```
# To delete a deny 80 rule
ufw delete deny 80
or
ufw delete $SERIAL_NO_OF_THE_RULE
ufw delete 3

# Check the status again to confirm the deletion
ufw status

```
