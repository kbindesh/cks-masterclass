# User Privilege Escalation

In this section, you will learn how to elevate the access levels of a Linux user to perform any adminsitrative tasks adhering to security best pratices.

## Useful Linux Commands

```
# You can add a user to the sudoers file in order to allow

# To install a package with a sudo privileges
sudo apt install docker

# To disable to root login directly
grep -i ^root /etc/passwd
```

## Useful Linux Files

```
# Sudoers file | Good for global defaults and core system-wide rules
/etc/sudoers

# Sudoers directory | Good for modular rules for specific users, teams or applications
/etc/sudoers.d/

/etc/ssh/sshd_config
```

### To check if a User is part of a Group that typically has `sudo` privileges

```
# Method-01 - Check Groups | Quickly seeing all group memberships for a user
groups $USERNAME

# Method-02 - List Group Members | Seeing everyone who has "admin" group access
getent group sudo

# Method-03 - Check Active Rules | Verifying actual permissions, including direct sudoers file entries
sudo -l -U $USERNAME
```

### Sudoers File

```
# View contents of sudoers file
sudo cat /etc/sudoers

# Syntax of sudoers file entries - Example
bindesh ALL=(ALL:ALL) ALL
```

- A sudoers file entry follows the general format:

```
[User] [Host] = ([Runas_User]:[Runas_Group]) [Command]

[This structure specifies which user can run which command on which host, and as which target user (or group)]
```

| Field   | Description                                                                                      | Example values                             |
| ------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| User    | The user or group who is granted the privileges.<br>Groups are prefixed with %                   | bindesh, %wheel, ALL                       |
| Host    | The hostname(s) where the rule applies.<br>Usually set to ALL in single-machine setups.          | localhost, ALL, webserver                  |
| RunAs   | (Optional) The user and/or group the command is executed as.<br>If omitted, it defaults to root. | (ALL),<br>(root:operator),<br>(DB)         |
| Command | The absolute path to the command(s) allowed.<br>Can include arguments, wildcards, or aliases.    | /usr/bin/passwd,<br>ALL,<br>!/usr/bin/kill |
