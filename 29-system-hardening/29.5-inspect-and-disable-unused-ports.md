# Inspect and Disable unused Linux Ports

- As a recommeded security paractice, we must restrict access to systems on unused port and shouldn't leave it open

## Useful Commands

```
# To check the status of a service
systemctl status $SERVICE_NAME
systemctl status ssh

# To check which TCP connection running on the system along with port specs
netstat -an | grep -w LISTEN

# To get more information about the running TCP connections, check /etc/services file - Ex. port 53
cat /etc/services | grep -w 53
```
