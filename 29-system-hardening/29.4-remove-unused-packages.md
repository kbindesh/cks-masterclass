# Remove Unused from the Kubernetes Nodes

## Best Practices

- Keep only the required packages on the Nodes and remove other:
  - kubectl
  - kubelet
  - Container runtime
  - kubeadm

- Keep existing packages up-to-date with all the neccessary updates

- Stop any service which is not really required:

```
# List all the Services
systemctl list-units --type=service

# List all the Running Services
systemctl list-units --type=service

# To check the status of a particular Service
systemctl status $SERVICE_NAME
systemctl status sshd

# To Stop a Service
systemctl stop $SERVICE_NAME
systemctl stop jenkins

# To Disable a Service
systemctl disable $SERVICE_NAME
systemctl disable jenkins
```

- Remove the unnecessary packages after stopping the relevant services:

```
apt remove $PACKAGE_NAME
apt remove jenkins
```
