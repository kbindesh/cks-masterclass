# Open Policy Agent (OPA)

## OPA Overview

- Open Policy Agent is an open-source, general-purpose policy engine that unifies policy enforcement across the cloud-native stack.
- It enables "policy-as-code"
- It allows teams to define rules using a high-level declarative language called `Rego` and decouple authorization logic from application code.

## How OPA works?

- **Request**
  - A service (e.g., Kubernetes API) sends a query to OPA with a JSON request.
- **Evaluate**
  - OPA evaluates the request against loaded policies (Rego) and data.
- **Decision**
  - OPA returns a JSON decision (e.g., allow: true or false) to the service.
