# Upgrade the Kubernetes cluster

## Lab: Upgrading kubeadm based Kubernetes cluster

- It is important to upgrade the k8s cluster in sequential way 1.31->1.32->1.33.

- If you're planning to upgrade k8s version, you'll have to upgrade both control plane and worker nodes
- _kubelet_ doesn't upgraded along with _kubeadm_ upgrade process. Needs manual upgrade seperately.

### Prerequisites

- Create a K8s cluster with at least 1 master and 1 worker node.

- You may bootstrap K8s cluster using kubeadm: https://kubernetes.io/docs/setup/production-environment/tools/kubeadm/create-cluster-kubeadm/

- Ensure the nodes are up and running:

```
kubectl get nodes
```

### Check the current K8s version

```
# Check kubeadm version
kubeadm version

# List nodes | observe the version
kubectl get nodes -o wide
```

### Get the K8s Upgrade Plan

```
# View kubeadm upgrade plan
kubectl upgrade plan
```

- Based on the preceding command output, you can plan your upgrade process i.e. in this lab, from version **v1.31.0** to **v1.31.14**

### Upgrade Control Plane Nodes

- Unhold following k8s programs in order to upgrade it:

```
sudo apt-mark unhold kubelet kubeadm kubectl
```

- To list all the available kubeadm packages in current repo:

```
apt-cache madison kubeadm
```

- If the preceding command list the kubeadm version that you want to upgrade to, you can simply use the existing repo and skip the next step.

- (Optional) Configure repo for newer version if the existing repo doesn't list the target k8s package version e.g. in this lab, it is v1.31.14

```
# Configure repo for newer version
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.32/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg

echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.32/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list

apt-get update
```

- **Install and Upgrade `kubeadm`**

```
# list available "kubeadm" packages in current repo
sudo apt-cache madison kubeadm

# Update Package Manager
sudo apt-get update

# Install and Upgrade "kubeadm" from 1.31.0 to 1.31.14 on control plane node(s)
sudo apt-get install -y kubeadm="1.31.14-1.1"

# Upgrade the K8s Control plane
sudo kubeadm upgrade apply v1.31.14
```

- **Install and Upgrade `kubelet` and `kubectl`**

```
# List available "kubelet" packages in current repo
sudo apt-cache madison kubelet

# List available "kubectl" packages in current repo
sudo apt-cache madison kubectl

# Install kubelet and kubectl version 1.31.14 on control plane node(s)
sudo apt-get install -y kubelet="1.31.14-1.1" kubectl="1.31.14-1.1"
```

- **Restart the kubelet service to apply the new version**

```
sudo systemctl daemon-reload

sudo systemctl restart kubelet
```

- Re-enable the hold to prevent accidental upgrades in the future:

```
sudo apt-mark hold kubeadm kubelet kubectl
```

- Verify the K8s control plane upgrade

```
kubeadm version

kubectl get nodes -o wide

[The control plane node must show the upgraded version i.e. 1.31.14]
```
