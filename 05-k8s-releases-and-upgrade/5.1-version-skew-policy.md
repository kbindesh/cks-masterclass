# Kubernetes `Version Skew Policy`

## Version Skew Policy - Overview

| Component      | Version Skew                                                                                                                                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| kube-apiserver | In Highly Available (HA) clusters, the newest and the oldest kube-apiserver instances must be within one minor version.<br><br>Example: If the newest kube-apiserver has version 1.34, other kube-apiserver instances will support 1.34 and 1.33 only |
| kubelet        | kubelet must not be newer than kube-apiserver<br><br>kubectl can be upto three minor versions older than kube-apiserver<br><br>Example: If kube-apiserver version is 1.34, the supported kubelet versions will be 1.34, 1.33,1.32,1.31                |
